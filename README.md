## What I'm working on

- **[MACD Adaptive](https://macd.ie)** - an online booking system with automated reminders, small-business websites and WhatsApp ordering, with a focus on accessibility and plain-language service.
- **[Almojarife](https://github.com/HALCONDEORO/almojarife-game)** - a free, open-source sea-trading game set on the Iberian and Mediterranean coast (15th-16th century). Desktop browser game, English and Spanish. Early development.
- **[Sign-language mosaic](https://halcondeoro.github.io/jw-sign-mosaic/)** - a personal video-wall page that plays sign-language videos from a public streaming catalog, many at once, with a live ES/EN interface.
- **Open-source contributions** - fixes and tooling proposals to other maintainers' projects, e.g. [gramps-web-toolkit](https://github.com/GeiserX/gramps-web-toolkit) (CLI tools around Gramps Web; pull requests open).
